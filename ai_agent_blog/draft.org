- Strata, Strata-Lite で Qwen3.8 Flash Next, Gemma4 26B A4B を動かしてみた
- Strata は Qwen3.8 Flash Next(125B) を 12GB の VRAM で動かすという
  ローカル LLM ユーザにとってありがたい LLM エンジン
- https://github.com/Niko1221/Strata  
- 実際に手元の RTX 5070Ti で動かすと 100 tps 前後の性能が出るという凄まじい実効性能を叩き出す
- ただ、悲しいかな Qwen 系はパラメータ数が大きくても日本語が不自由という欠点がある
- いや、説明文やお堅い文章なら良いのかもしれない。口語などの日常表現がともかく苦手に感じる。
- Qwen3.8 Flash Next は、チャットボットではなく coding エージェント向きだ、という話も聞くので、
  そういう用途には十分な性能を発揮するのかもしれない。
- ということで、個人的に OSS の中では日本語に強いと感じている Gemma4 で、
  Strata に似たアイデアの LLM エンジンがないかと調べた
- その;sdilju結果 Strata-Lite というプロジェクトを見つけた。 https://github.com/thed1c/Strata-Lite
- Strata-Lite はその名の通り Strata の fork で、ほぼ claude code によって開発された OSS らしい
- 現時点でスター数は 2。現時点でそもそもリリースされてから 2 日しか経っていないのである意味しかたがないだろう。
- コードの中身を claude code で解析したが、特に怪しい処理は見当らない、ということだったので、
  実際に動かしてみた
- その結果としては、 Gemma4 26B A4B が RTX5070Ti で 100 tps 越えという実行性能を出した
- なお、 llama.cpp の バージョン v0.6.0 では 50tps 前後なので、約倍の性能になった
- claude に llama.cpp に今後 Strata-Lite のような対応が入るのか？と聞くとすでに一部取り込まれている、
  とのことだった。ただ v0.6.0 では使えないらしい。
- とはいえ、数週間後には入っているだろう。
- Strata-Lite は、それまでの繋ぎとして使うには十分なツールと言える
